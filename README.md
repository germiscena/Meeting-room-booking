# Meeting Room Booking

Приложение для бронирования переговорной комнаты, реализованное в рамках тестового задания на позицию Frontend Developer.

## Описание проекта

Интерфейс позволяет просматривать расписание на день, выбирать доступные временные слоты и управлять бронированиями (создание, редактирование, удаление). Бизнес-логика строго отделена от UI и валидируется как на клиенте, так и на мок-сервере.

## Что реализовано

Все требования ТЗ успешно выполнены:

- **Просмотр и навигация**: выбор даты, просмотр существующих бронирований (в виде списка и наглядного таймлайна с шагом 15 минут).
- **Управление бронированиями**: создание, редактирование и удаление встреч с опциональным указанием названия (до 60 символов).
- **Бизнес-правила**:
  - Рабочий день строго с 09:00 до 18:00.
  - Длительность встречи от 30 минут до 2 часов (выбор времени осуществляется пошагово по 15 минут).
  - Запрет на пересечение бронирований (касание границ допустимо).
  - Запрет на бронирование прошедшего времени. Для текущего дня доступность слота рассчитывается с буфером в 2 минуты до начала.
  - При редактировании встреча не конфликтует сама с собой.
- **Отказоустойчивость**: полноценная обработка сетевых гонок (Race Conditions) и ошибок `409 Conflict`. При конфликте форма сохраняет введенные данные, а расписание обновляется в фоне для отображения актуальной занятости.
- **Адаптивность и доступность**: интерфейс адаптирован для мобильных устройств, диалоговые окна поддерживают фокус-ловушки и клавиатурную навигацию, элементы снабжены `aria`-атрибутами для Screen Readers.

## Что не реализовано

- **Все требования исходного ТЗ выполнены в полном объеме.** Невыполненных функциональных требований нет.

## Запуск проекта

Убедитесь, что у вас установлен Node.js (рекомендуется v20+).

1. Установите зависимости:

```bash
npm install
```

2. Запустите сервер для разработки:

```bash
npm run dev
```

После этого откройте приложение по адресу, указанному в терминале (обычно `http://localhost:5173`).

### Дополнительные команды

- `npm run test` — запуск всех тестов (Unit, Integration, E2E) через Vitest.
- `npm run typecheck` — проверка типов TypeScript.
- `npm run build` — сборка production-бандла.
- `npm run preview` — локальный запуск собранного production-бандла с проверкой API.

## Стек технологий

- **Frontend Framework**: React 18
- **Язык**: TypeScript
- **Сборщик**: Vite
- **Управление состоянием и API**: TanStack Query (React Query)
- **Формы и валидация**: React Hook Form + Zod
- **Стилизация**: Tailwind CSS + `clsx` / `tailwind-merge`
- **Мокирование API**: MSW (Mock Service Worker)
- **Тестирование**: Vitest + React Testing Library

## Затраченное время

На разработку приложения затрачено ~ 5 часов.
